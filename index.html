Gestion des données

Les données sont enregistrées localement dans le navigateur de cet appareil. Elles ne sont pas automatiquement synchronisées avec les autres appareils ou avec les autres membres de GKM.

Guide rapide

  1. Ajoute les équipes et leurs effectifs dans ÉQUIPES.
  2. Ouvre MATCH LIVE et choisis les deux équipes.
  3. Crée le match, sélectionne l'équipe puis le joueur.
  4. Ajoute les points, rebonds, passes, interceptions, contres, fautes et pertes de balle.
  5. Termine et archive le match pour alimenter les classements.
  6. Consulte les leaders et exporte régulièrement une sauvegarde.
